# SIRIUS interactive demo

This is a static, frontend-only demonstration. It has no connection to the SIRIUS API or CMD-Gen pipeline. Candidate names, structure drawings, SMILES strings, molecular properties, and Vina-like values are illustrative fabricated data; they are not generated or scientifically meaningful.

## Run locally

Open `index.html` in a browser, or serve this folder with any static HTTP server.

## Deploy online

Upload the **contents of this `demo` folder** to a static host such as Netlify Drop, Cloudflare Pages, GitHub Pages, or another static website host. Set the publish directory to `demo` if deploying from the repository root. No Python backend, GPU, checkpoints, build step, or environment variables are needed.

The upload control only displays the selected local filename; it does not read, upload, or process the file. The run button animates a simulated progress sequence. Keep the visible demo labels and disclaimer when sharing this page so visitors understand the outputs are examples.
