# Complete protein-ligand example complexes

Put all 20 complete structures in this folder. Each file contains both the protein and its bound small-molecule ligand. Upload any one of these files in the app under **Protein-ligand complex**. The app extracts the protein and calculates the pocket center from the ligand automatically; no coordinates or receptor/ligand pair files are needed. Then click **Generate and dock molecules**.
